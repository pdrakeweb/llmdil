The Rust function below is supposed to compute a running median of a stream of f64 values, but it has bugs: it panics on some inputs, returns wrong results on others, and is slower than it needs to be.

```rust
fn running_median(values: &[f64]) -> Vec<f64> {
    let mut out = Vec::new();
    let mut seen: Vec<f64> = Vec::new();
    for v in values {
        seen.push(*v);
        seen.sort_by(|a, b| a.partial_cmp(b).unwrap());
        let n = seen.len();
        if n % 2 == 1 {
            out.push(seen[n / 2]);
        } else {
            out.push((seen[n / 2] + seen[n / 2 + 1]) / 2.0);
        }
    }
    out
}
```
